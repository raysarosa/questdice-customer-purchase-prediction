# QuestDice – Customer Purchase Prediction 🧠🛒

This project was developed as part of a Kaggle-style competition organized at NOVA IMS, aiming to predict whether customers would purchase a new board game product based on survey responses and demographic data.

## 📁 Project Summary

We explored, engineered, and modeled customer data using various supervised learning techniques. Our final model – a **Stacking Classifier** – achieved an F1 score of **0.947** on the validation set.

## 🔍 Problem Statement
A board game company wants to launch a new product. Based on data collected from a previous release, the goal is to predict whether customers will buy the new game.

## 🧰 Tools & Technologies
- Python (Pandas, NumPy, Scikit-learn)
- Jupyter Notebook
- Classification Models:
  - Random Forest
  - Gradient Boosting
  - SVC
  - Neural Networks
- Feature Selection (RFE, Chi-Square, Lasso, MIC)
- Hyperparameter Tuning
- Model Stacking (Meta-model: Random Forest)
- Evaluation Metric: **F1-score**
